# 公开边界与私有映射

## 公开原则

作品集采用“重新建模、最小披露、可执行验证”。公开的是可解释的业务不变量和工程方法，不是企业系统副本。

## 映射表

| 私有项目能力 | 作品集中如何呈现 | 处理方式 |
| --- | --- | --- |
| 设备台账、计划、任务、记录、证书 | 领域对象与架构图 | 重构后公开 |
| 状态流转与业务守卫 | `CalibrationWorkflow` 及失败路径测试 | 保留不变量，改写存储与命名 |
| 证书匹配置信度 | `CertificateMatchEvaluator` | 保留可解释评分思想，使用合成样例 |
| 分批回件与领取 | `SubmissionReturnWorkflow` | 保留部分完成和幂等规则 |
| 权限、审计、事务 | 文档说明与领域事件 | 不复制真实权限矩阵和数据库实现 |
| Laravel/Filament 页面 | 一张合成数据截图 | 不复制后台、路由或真实页面数据 |
| 真实迁移、Seeder、数据库 | 不公开 | 完全排除 |
| 企业、车间、人员、设备、证书 | 不公开 | 完全排除 |
| 域名、服务器、网络、VPS、边界层 | 不公开 | 完全排除 |
| 通知机器人、Webhook、Token、密钥 | 不公开 | 完全排除 |
| 备份、恢复、运维日志、事故记录 | 不公开 | 完全排除 |
| 原 README、PLAN、完成归档与提交历史 | 重新编写公开说明 | 不复制原文与历史 |

## 明确未复制

- 私有仓库的 `.git`、远端地址、分支、提交哈希和作者信息。
- `.env`、`.env.example`、Docker/Nginx/Cloud 配置、服务器脚本。
- 运行期数据库、上传目录、证书原件、日志、缓存、备份和导出文件。
- 真实账号、邮箱、组织名称、内部编号、车间代号和业务统计。
- 通知模板、群配置、签名密钥、只读 API Token 和外部访问说明。
- 内部阶段计划、部署工作日志、故障记录和领导演示材料。

## 合成素材

`assets/calibration-plan-demo.jpg` 来自私有项目专门制作的演示画面，使用通用仪表类别、虚构月份和小规模合成数量，并明确标注“演示数据”；作者已将其纳入本作品集的公开范围。

## 可逆决策

- 公开仓库名为 `measurement-portfolio`；只推送本作品集的新历史，不连接或镜像私有仓库。
- 当前采用非开源的作品集评估许可证；未来如需开放复用，可另行评估 MIT、Apache-2.0 等标准许可证。
- 若未来需要公开完整 Laravel 演示应用，应另建任务重新做源码、依赖、数据库和 UI 全面审计，不能直接扩大本仓库范围。
