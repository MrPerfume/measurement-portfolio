# 公开边界

## 原则与当前状态

公开的是重新建模的业务判断、合成原型和可重复测试，不是企业系统副本。2026-10-01 已获授权并通过 PR #5 部署六场景版本；后续修订以 Pages 工作流与对应验收为准，见[发布复核](INTERACTION_QA.md#publication-20261001)。发布授权不扩大到业务系统部署或 GitHub 个人资料调整。

## 内容边界

| 内容 | 本仓库保留 | 明确排除 |
| --- | --- | --- |
| 三个角色与六场景 | 合成状态、公开重新编写的 HTML/CSS/JavaScript | 真实身份、权限矩阵、后台页面源码 |
| 周报检、交接与复核 | 对象关联、状态守卫、幂等、审计与人工确认规则 | 真实业务数据、数据库、并发适配器 |
| PHP 领域内核 | 既有独立规则与测试 | 私有框架适配器、迁移与业务代码复制 |
| 三张新案例图 | 本公开原型截图，标注“交互原型” | 真实文件上传、PDF 与证书原件 |
| 原六张后台图 | 隔离环境合成截图，单列来源 | 真实客户或生产界面数据 |
| 性能案例 | 日期、测量范围、前后中位数和限制 | 内部原始记录、环境地址、提交标识、运维记录 |
| 两则近期业务实践 | 部门进度与移动清单的重新编写说明，非本站交互 | 真实通知、清单、签名链接、内部验证资料 |

## 运行时边界

- 六场景直达 URL 仅保存场景标识，不保存业务事实或草稿，不改变内存模式。构建为样式与整个模块依赖图附加同一内容版本，避免旧缓存混用合成数据契约。

- 所有状态仅在当前页面内存，刷新或重置恢复完整初始样例。
- 不增加登录、数据库、远程 API、文件上传、消息发送、统计、Cookie 或浏览器持久化。
- 表单只触发本地状态转换，不提交数据到服务器；运行时 CSP 禁止连接与表单外发。
- 字体、图片、样式、脚本只使用同源资源；公开外链只指向本仓库、文档、Actions、Pages 和作者公开 GitHub Profile。
- 角色切换是可见的业务分工模拟，不是真实身份鉴权。

## 构建与开发工具边界

`.pages-dist/` 仅包含页面、显式收录的状态模块、合成数据、三张案例图和原六张截图。Node 测试、Playwright、npm 依赖、浏览器报告和本地服务脚本不进入站点。

开发 URL 只在指定测试/配置脚本中允许精确的本地服务地址；锁文件只允许实际三个 Playwright 包的下载地址。它们不扩张运行时 URL 白名单。

所有新增文件、图片和公开说明都在公开仓库独立制作；不复制私有源码、计划原文、Git 历史、内部提交标识、环境路径、部署记录或作者私密元数据。

## 本轮未模拟与发布闸门

不模拟完整撤销、返工、跨周补充单、真实签名链接、并发数据库、真实消息或 PDF/OCR。扩大为完整应用或接入远程数据、统计、身份认证，需要重新审查数据去向和授权。

未来明确授权发布后，才新建 `codex/` 分支、使用中文提交与隐私安全作者身份、推送 PR；核对 CI 后合并检查 Pages。回滚使用正常回退提交，不强制推送、不改写历史。本轮没有执行这些外部操作。许可证保持[作品集评估边界](LICENSE_AND_DATA_BOUNDARY.md)，不自动转成开源授权。
