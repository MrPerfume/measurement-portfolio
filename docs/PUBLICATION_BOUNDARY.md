# 公开边界

## 原则与当前状态

公开的是重新建模的业务判断、合成原型和可重复测试，不是企业系统副本。2026-10-11 PR #7 内容修订已发布，仓库简介及作品集置顶第一完成，见[上一次回执](https://github.com/MrPerfume/measurement-portfolio/pull/7#issuecomment-6106231985)。本轮招聘表达与导航优化已获实施、测试／CI 后发布 Pages，以及上线后个人主页 Bio／Website 更新授权；保持现有置顶顺序和其他项目，不涉及业务系统部署或额外个人资料。

## 运行时边界

- 六场景直达 URL 仅保存场景标识，不保存业务事实或草稿，不改变内存模式。构建为样式与整个模块依赖图附加同一内容版本，避免旧缓存混用合成数据契约。
- 新增案例锚点 `#cases`，保留 `#top`、`#demo`、`#evidence`；阅读入口与引导不创建业务事实，既有会话角色、对象和草稿保持。错误提示按场景表述，不放宽校验。

- 所有状态仅在当前页面内存，刷新或重置恢复完整初始样例。
- 不增加登录、数据库、远程 API、文件上传、消息发送、统计、Cookie 或浏览器持久化。
- 表单只触发本地状态转换，不提交数据到服务器；运行时 CSP 禁止连接与表单外发。
- 字体、图片、样式、脚本只使用同源资源；公开外链只指向本仓库、文档、Actions、Pages 和作者公开 GitHub Profile。
- 角色切换是可见的业务分工模拟，不是真实身份鉴权。

## 构建与开发工具边界

`.pages-dist/` 仅包含页面、显式收录的状态模块、合成数据、三张案例图和原六张截图。Node 测试、Playwright、npm 依赖、浏览器报告和本地服务脚本不进入站点。

开发 URL 只在指定测试/配置脚本中允许精确的本地服务地址；锁文件只允许实际三个 Playwright 包的下载地址。它们不扩张运行时 URL 白名单。

所有新增文件、图片和公开说明都在公开仓库独立制作；不复制私有源码、计划原文、Git 历史、内部提交标识、环境路径、部署记录或作者私密元数据。

## 本轮未模拟与发布闸门

不模拟完整撤销、返工、跨周补充单、真实签名链接、并发数据库、真实消息或 PDF/OCR。扩大为完整应用或接入远程数据、统计、身份认证，需要重新审查数据去向和授权。

本次按已授权范围使用 `codex/portfolio-recruiter-polish` 分支、中文提交与隐私安全作者身份，通过 PR / CI 后合并检查 Pages。回滚使用正常回退提交，不强制推送、不改写历史。许可证保持[作品集评估边界](LICENSE_AND_DATA_BOUNDARY.md)，不自动转成开源授权。
