## 2026-09-15 新案例体验优化

本地未提交工作树验收；不发布、不连接业务系统。目标是让招聘方始终知道当前对象、下一步和失败原因。沿用现有设计，只调整三个新场景的任务层级、阅读顺序、焦点与草稿边界，不重做视觉方向或业务流程。固定演示日期仍为 2026-09-07，不随本次验收日期变化。

### 先复现，再修复

- **已确认缺陷**：390×844 下确认证书后，下一份标题留在视口上方，只剩新表单底部；交接空选择失败时，提示位于视口上方约 1,123px。两项新增浏览器用例在修改前均以视口可见断言失败。
- **有依据的体验问题**：证书队列、规则先于当前材料，周单未建立先展示四块零值统计，交接两种动作共用同一选择清单。改为当前工作优先、辅助队列后置、独立取回/领取清单和任务定位。
- **实现期防回归**：多个计划组同屏时，反馈按预约 ID 归属；取回和领取草稿分别保存，成功只清本项。草稿状态用例先失败，再完成实现。
- **覆盖复盘**：9 月 7 日测试验证了内容、状态和可点击性，没有证明换份后标题或失败提示仍在视口内。其“无未解决 P0/P1”只是当时有限覆盖下的结论，不能作为本次发现的反证；现增加焦点、视口和多表单归属断言，并检查同类周单/交接模式。未扩写个人或项目规则文件。
