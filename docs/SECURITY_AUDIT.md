## 自动检查

运行：

```bash
bash scripts/verify.sh
```

检查项包括：

1. 所有 PHP 文件语法检查。
2. 领域测试执行。
3. `composer.json` 严格校验（本机存在 Composer 时）。
4. 禁止文件类型检查：环境文件、数据库、证书、表格、归档、私钥等。
5. 常见秘密格式检查：私钥头、云密钥、GitHub Token、Slack Token、JWT、Bearer Token、Webhook 赋值、密码赋值。
6. 公开边界检查：私有路径、真实部署/外部访问文档名称、原 Git 提交引用。

## 外部写入闸门

首次公开已在展示精确范围和不可逆风险后取得明确授权。任何扩大代码、数据、素材、部署面或外部集成范围的后续发布，都必须重新确认边界；已有授权不能自动扩张。
