## 自动检查

运行：

```bash
bash scripts/verify.sh
```

检查项包括：

1. 所有 PHP 文件语法检查。
2. 领域测试执行。
3. 交互状态机的 Node 边界测试。
4. GitHub Pages 构建、HTML 契约和站内资源引用检查。
5. `composer.json` 严格校验（本机存在 Composer 时）。
6. 禁止文件类型、常见秘密格式与私有路径检查。
7. 公网链接主机/路径白名单和 IPv4 地址检查。
